## 一、体系哲学

只交易两种被数据确认过的微观结构失衡，且各配一道与信号时间尺度匹配的行情闸门：

1. 跌势中反弹至阻力区、但现货买盘枯竭 → 空头延续（S10）
2. 恐慌抛售流枯竭、动量仍在中轴上方 → 超跌反弹（S20）

一切参数的合法性来自：训练/样本外同号、双品种一致、参数平台而非尖峰。

## E层 · 实盘执行章（v2.1 新增）

来源：Kurisko(HPS体系)执行纪律，经系统化适配。原则：**运行时规则分三级，级别决定上线门槛**。

### E1 工程护栏（不改变交易分布，直接生效，bot v10 起）
- 数据守门：K线不足400根 / 相邻收盘跳变>20% / taker流为空 → 跳过该品种该轮 + TG告警
- 账本自洽：每轮开工前校验 净值 = 本金 + Σ已平仓盈亏（容差$0.05），不符则暂停开单+告警
- 止损即挂：止损为引擎结构件（L01），入场即生效，系统内不存在"心理止损"
- 播报可靠性：周报发送成功才置位，失败下小时自动重试；手动补发走 workflow_dispatch mode=report

### E2 影子熔断（记录不执行，攒满样本后串行重放裁决）
- 单策略单日累计 ≤ -1.5R → 记 SHADOW_HALT_DAYR
- 单策略当日连亏 ≥ 3 笔 → 记 SHADOW_HALT_STREAK
- 每笔入场记 ENTRY_ATR（波动率减仓假设的原始数据）与 BACKFILL_ENTRY（补检单标记）
- **裁决协议**：前向 ≥30 笔后，串行重放"有熔断 vs 无熔断"净值差；正差才许转正为真熔断。
  熔断本质是过滤器，过滤器不经串行重放不许上线（MIN_STOP教训）。Kurisko 的规则治的是
  裁量交易员的情绪，系统没有情绪——它对系统化策略是否有效是待证伪假设，不是公理。

### E3 实盘迁移清单（首匹马过红线时启用）
- 资格线 = 实盘红线（前向≥30笔、净期望>0、与回测偏差可解释；s2/s3系另需≥15笔）——这就是我们的"A级"，只有A级配真钱
- 起步仓位：红线通过后首月用赛马名义的 1/10，月度对账（胜率/均R/止损分布 vs 纸面）无偏离才升档
- 滑点重估：纸面用0.07%单边，实盘首月实测滑点重算期望，若净期望转负立即退回纸面
- 人工干预条款（唯二允许）：只许减仓不许加仓；只许提前止损不许挪远止损。每次干预必须记录并在周报披露
- 每笔实盘记录：R倍数、进出场原因、是否守规则；月度复盘按"守规亏损>违规盈利"原则评分
- 停止条件：实盘累计回撤 ≥ 15% 或与纸面轨迹偏差无法解释 → 全部退回纸面
